实现本地安全发布闸门，处理全部合成的软件版本、依赖清单和已登记风险项。风险项绑定租户、应用、依赖内容摘要与危害等级，只有用户提供的模拟签字状态有效。应用发布必须覆盖整条依赖闭包，未修复的普通风险需要两名不同岗位的人员对本次版本和确切风险项分别审批，严重等级不得豁免。豁免同时绑定修复截止、目标发布环境及证据版本；审批人换岗、延期或风险严重度上调后旧审批失效。

用 SQLite 实现受保护上线操作和审计，用户创建的两个独立进程可并发审批、撤销和请求发布。支持先产生只读上线预检，再在事务内重验完整依赖和授权，公开版本指针及回执同事务更新。历史成功回执保持可查，当前上线查询按环境当前授权或修复信号只读核验。预检后增加一个间接风险、审批权撤销再发、候选版回到曾见摘要均要重新判断。

用独立进程固定发布、升级风险、写豁免彼此争用的顺序。终止自己的工作进程于指针写入未提交和已提交未响应，核对恢复结果、证据哈希及请求重放。另测同一依赖经菱形引用跨两个应用、不同版本共用相同软件名、到期同时发布及双岗位由同一人注册。仅使用元数据，程序不连接或修改任何真实系统。

在 Windows 原生 Python 3.12、标准库和 CPU 环境下实现，全部输入自行合成，离线测试。交付源码、README、可重放 cases.json 和自动化测试。提供 python -m solution --input cases.json --output result.json 与 python -m unittest discover -s tests -v。测试须断言具体结果，README 写明规则、输入输出、错误码和实测结果。
